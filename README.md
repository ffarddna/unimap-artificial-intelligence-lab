# Artificial Intelligence — Python Lab 

## Overview
This repository contains practical laboratory exercises completed as part of **IMC21203 Artificial Intelligence** at Universiti Malaysia Perlis (UniMAP).

The labs explore fundamental Artificial Intelligence concepts through Python programming, including rule-based decision-making, intelligent agents, supervised machine learning, and decision evaluation.

## Lab 1: Introduction to Artificial Intelligence

**Topic:** Rule-Based Intelligent Agents

**Objective:** Develop a cleaning robot agent that makes decisions based on its environment.

**Implementation:**
- Created a rule-based decision function using Python conditions.
- Developed a simple reflex agent to clean and move between two rooms.
- Simulated the cleaning environment and tracked the robot's actions.
- Improved the agent to stop automatically once both rooms were clean.

**Key Learning:** Understanding how intelligent agents perceive their environment, make decisions, and achieve goals using predefined rules.

## Lab 2: Machine Learning Foundations

**Topic:** Rule-Based AI vs. Supervised Machine Learning

**Objective:** Compare manually defined classification rules with a machine learning model using the Iris dataset.

**Implementation:**
- Loaded and explored the Iris dataset using Pandas and Scikit-learn.
- Developed a rule-based flower classifier.
- Split the dataset into training and testing sets.
- Trained a Decision Tree classifier.
- Evaluated model performance using accuracy and a confusion matrix.
- Compared rule-based predictions against machine learning predictions.

**Key Learning:** Understanding how supervised learning uses labelled data to learn patterns, unlike rule-based AI, which relies on manually defined conditions.

## Lab 3: Intelligent Agents

**Topic:** Simple Reflex Agents, Memory-Based Agents, and Utility

**Objective:** Explore how different intelligent agents select actions using observations, memory, and utility calculations.

**Implementation:**
- Developed a simple reflex agent using IF–ELSE conditions.
- Implemented a memory-based agent to track previously observed room conditions.
- Added a stopping rule when both rooms were known to be clean.
- Tested different observation sequences.
- Calculated utility scores to compare decision-making plans.

**Key Learning:** Understanding how memory and utility functions improve agent decision-making beyond simple reactive behaviour.
